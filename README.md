# Hunter Order

Persistent browser MMORPG built in public.

> The player is not the protagonist. The world is.

## Repository status

This repository is in bootstrap phase. The initial target stack is:

- Client: TypeScript, Phaser, React and Vite
- Server: .NET 10 and ASP.NET Core
- Persistence: PostgreSQL
- Local infrastructure: Docker Compose
- Tests: xUnit, Vitest, Playwright and Testcontainers
- Observability: OpenTelemetry
